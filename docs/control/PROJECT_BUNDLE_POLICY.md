# Project Bundle Policy

## Purpose

Project bundles capture immutable snapshots
after lifecycle milestones.

A bundle represents a frozen governance state.

---

## Trigger Events

A bundle MUST be generated after:

- Stage-3 closure
- Phase completion
- Transition to Maintenance Mode

---

## Rules

- Bundles are immutable
- Generated by script only
- No manual edits permitted
- Stored under artifacts/bundles/

---

## Authority

The latest bundle is the canonical
reference for audits and reviews.
