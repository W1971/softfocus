# SoftFocus — Orientation Screen (EN Canon)

## Purpose

The Orientation Screen is the primary intellectual entry point of SoftFocus Web.

It does not:
- sell
- persuade
- promise outcomes
- guide user behavior

It provides structural orientation only.

---

## Canonical Copy

### Title

SoftFocus

### Hero

Structural assessment of recovery  
under sustained cognitive load.

### Lead

SoftFocus reflects whether recovery closes  
when responsibility remains constant.

The interpretation is analytical and non-clinical.  
It does not provide diagnosis or recommendations.

---

### Functional Action

Start assessment

This is a functional action.  
It is not a promotional call-to-action.

---

## Structural Section

### How SoftFocus is structured

**Assessment**  
→ structured classification of recovery state.

**Guides**  
→ mechanism-based explanation using consistent terminology.

**Protocol**  
→ reference model aligned with interpretation.

---

## Boundary

SoftFocus is a non-clinical analytical system.  
It does not replace medical or psychological evaluation.

---

## Design Principles

- Light background
- Minimalist layout
- Academic tone
- No growth UI
- No marketing language
- No persuasive framing
- Generous whitespace
- Strict typographic hierarchy
