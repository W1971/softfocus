# SoftFocus Mobile Flow — Final Object

## Entry
User enters at any point.
No preparation assumed.

## Flow

Assessment
→ Result Orientation
→ (Optional) Reference
→ Exit

No branching.
No loops.
No upsell.

## Termination

Exit is:
- explicit
- complete
- not reversible by design

The product does not try to retain the user.

## Invariants

- No motivation
- No optimization
- No improvement narrative
- No progress framing

## Success Condition

The product succeeds if:
- the user stops thinking about “what to do”
- the user gains clarity

Nothing else is measured.
