# Stage-4 — Visual Layer Declaration

## Purpose

Stage-4 allows refinement of the mobile visual layer
without affecting meaning or interaction.

---

## Allowed Changes

- typography tokens
- spacing scale
- color tokens (non-emotive)
- contrast adjustments

---

## Forbidden Changes

- interaction affordances
- navigation behavior
- semantic emphasis
- completion signals

---

## Preconditions

- Stage-1: PASS
- Stage-2: PASS
- Stage-3: PASS

All preconditions are satisfied.

---

## Enforcement

Stage-4 does not override earlier stages.
Any regression in Stage-1–3 blocks merge.
