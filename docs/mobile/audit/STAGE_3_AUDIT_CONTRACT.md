# Stage-3 Mobile Interaction UI Audit — Contract

Stage-3 validates the **interaction semantics** of the mobile UI.

This stage does NOT evaluate:
- visual design
- copy quality
- UX preference
- effectiveness or conversion

It evaluates ONLY:
- what happens when a user interacts
- whether UI responses imply guidance
- whether interaction outcomes are deterministic

---

## When Stage-3 is REQUIRED

Stage-3 audit is mandatory if changes affect:
- mobile screens
- interaction flows
- button behavior
- navigation logic
- state transitions
- user-triggered outcomes

---

## PASS Criteria (ALL REQUIRED)

Stage-3 may be marked PASS only if:

- UI does not instruct, encourage, or recommend
- UI reactions are explainable and reversible
- No hidden or implicit “best choice” signaling exists
- No interaction implies behavioral correction
- All interaction states are documented

---

## FAIL Is a Valid and Expected State

FAIL means:
- audit not yet completed
- or interaction layer under review

FAIL blocks merge by design.

There is NO override.

---

## Governance Principle

Stage-3 protects SoftFocus from becoming:
- a coaching tool
- a behavioral system
- a persuasive interface

This gate is non-negotiable.
