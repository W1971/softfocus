# Mobile as Distribution Endpoint

## Definition

SoftFocus mobile is a **terminal distribution endpoint**.

It does not:
- capture users
- retain users
- redirect users
- grow funnels

---

## Entry Sources

Mobile may be entered from:
- web assessment results
- direct links
- saved URLs

Entry source is irrelevant to behavior.

---

## Exit Semantics

Mobile does not route users elsewhere.

Exit means:
- completion
- no follow-up
- no continuation pressure

---

## Distribution Rule

Traffic may increase.
Usage may increase.

Behavior must not change.

Distribution does not justify UX change.

---

## Finality

Mobile exists to:
- deliver clarity
- end interaction

Any attempt to extend its lifecycle
violates this contract.
