# SoftFocus — Mobile Product Scope

Mobile is the **primary experiential embodiment**.

Responsibilities:
- quiet orientation
- assessments
- optional calculators

Mobile must work without explanation,
on first contact,
without return expectation.

### Runtime Baseline

SoftFocus Mobile operates exclusively on:
- Expo SDK 54
- React Native 0.81.x
- React 19.x

Deviation from this baseline is forbidden
without a new phase declaration.
