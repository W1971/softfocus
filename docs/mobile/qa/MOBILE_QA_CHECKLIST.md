# Mobile QA — PASS / FAIL

## PASS если:
- нет прогресса, таймеров, стриков
- нет советов и шагов
- результат — одно состояние
- выход возможен в любой момент
- нет визуального давления

## FAIL если:
- есть «следующий шаг»
- есть объяснение на экране
- есть удержание или возврат
- есть эмоциональная стимуляция

## Контрольный вопрос
Если макет нужно объяснять — FAIL.
