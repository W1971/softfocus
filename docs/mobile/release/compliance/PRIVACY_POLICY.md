# Privacy Policy — SoftFocus Mobile App

This Privacy Policy describes how the SoftFocus mobile application
handles user data.

---

## Overview

SoftFocus is designed to operate without collecting personal data.

- No account creation
- No user identification
- No analytics tracking
- No advertising identifiers

---

## Data Collection

SoftFocus does **not collect**:
- names
- email addresses
- location data
- health data
- usage analytics
- device identifiers

---

## Data Storage

- No personal data is stored locally or remotely
- No cloud storage is used for user data
- No third-party SDKs collect data

---

## Permissions

SoftFocus requests **no sensitive permissions**.

Any permissions required by the operating system
are used solely for basic application functionality.

---

## Third-Party Services

SoftFocus does not integrate with:
- analytics platforms
- advertising networks
- social login providers
- data brokers

---

## Children’s Privacy

SoftFocus does not target children
and does not knowingly collect data from minors.

This policy is frozen as part of Phase D.
Any change requires a new phase declaration.
