# Minimal Screenshots Guide
## App Store & Google Play

This guide defines the minimal screenshot set
that is safest for store review.

---

## Required Screenshots (Recommended: 1–2)

### Screenshot 1 — Result Screen (PRIMARY)

Must show:
- single analytical statement
- clean, neutral layout
- no buttons
- no CTAs
- no recommendations
- no medical language

This screenshot alone is usually sufficient.

---

### Screenshot 2 — Entry / Assessment Screen (OPTIONAL)

Use only if required by store.

Must show:
- neutral input or entry
- no guidance or persuasion
- no progress pressure

---

## What to Avoid (Critical)

Do NOT include screenshots with:
- advice text
- emotional language
- “next steps”
- encouragement or reassurance
- charts implying improvement
- monetization UI

---

## Caption Guidance

Captions should be factual and neutral.

Allowed examples:
- “Analytical result screen”
- “Assessment entry”

Forbidden:
- “Improve your recovery”
- “Reduce stress”
- “Get better results”

---

## Review Rule

If a reviewer can infer:
“this app tells me what to do” — the screenshot FAILS.
