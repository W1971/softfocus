# Review Notes — SoftFocus Mobile

SoftFocus is a non-clinical analytical application.

It does not provide:
- medical advice
- therapy or treatment
- recommendations or action plans

The app presents a single analytical result
and ends interaction without retention mechanics.

No user data is collected.
No accounts, payments, or tracking are used.

If further clarification is required,
we are happy to provide it.
