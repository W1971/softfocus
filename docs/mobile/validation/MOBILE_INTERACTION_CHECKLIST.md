# Mobile Interaction Checklist (Stage 3)

This checklist governs interaction and navigation behavior.

## Interaction Constraints

- No action-oriented CTAs
- No goal-directed navigation
- No progress or completion flows
- No habit or retention mechanics

## Navigation Rules

- Navigation must not imply next steps
- Exit is always valid
- No forced flows or loops

## State Handling

- No adaptive behavior
- No personalization
- No optimization logic

## Scope

- Interaction only
- No semantic changes
- No visual redesign

FAIL if any item is violated.
