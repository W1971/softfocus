# Web Orientation Screen

## Назначение
Orientation Screen — точка первичного понимания продукта SoftFocus в web.

Экран:
- не продаёт
- не вовлекает
- не обещает результатов
- не ведёт пользователя по сценарию

Он даёт **ориентацию и контекст**.

---

## Содержание экрана

### Заголовок
SoftFocus

### Текст (3–5 строк)
SoftFocus — аналитическая система ориентации
в состоянии восстановления при устойчивой когнитивной нагрузке.

Оценка носит неклинический характер
и не предоставляет диагнозов или рекомендаций.

---

### Разрешённое действие
- «Начать оценку»

Это **функциональное действие**, не CTA.

---

## Запрещено
- маркетинговые формулировки
- примеры кейсов
- обещания пользы
- инструкции «что делать дальше»

---

## Связь с продуктом
Orientation Screen ведёт **непосредственно в assessment**,
без промежуточных экранов.
