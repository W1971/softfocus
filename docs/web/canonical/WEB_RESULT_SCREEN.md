# Web Result Screen

## Назначение
Result Screen отображает **канонический результат**
анализа восстановления, сформированный калькулятором.

Экран:
- ничего не вычисляет
- не интерпретирует повторно
- не даёт рекомендаций

Он отображает **Result Contract**.

---

## Входные данные
- Result Contract v1.x
- Источник: app/shared/contracts/result.contract.schema.json

---

## Структура

### 1. Заголовок
Результат оценки

Подзаголовок (мелко):
Неклиническая аналитическая интерпретация

---

### 2. Состояние восстановления (Primary)

Отображается крупно:

- Восстановление закрывается
- Восстановление нестабильно
- Восстановление не закрывается

Источник:
- result.summary.state

---

### 3. Профиль нагрузки

Заголовок:
Профиль текущей нагрузки

Список:
- Доминирующий источник: {section}
- Удерживающий механизм: {mechanism}
- Предсказуемость восстановления: {stability}

Источник:
- result.profile.*

---

### 4. Интерпретация

2–5 строк текста.

Источник:
- result.interpretation.body[]

Правила:
- описательный язык
- отсутствие рекомендаций

---

### 5. Entitlement Depth (без UI-сигналов)

Если entitlement.present === true:
- показываются drivers (2–4)

Если false:
- drivers не отображаются

Причины различий не объясняются.

---

### 6. Граница

Мелкий текст:
Неклиническая оценка. Не является медицинским заключением.

---

## Разрешённые действия
- Повторить оценку
- Закрыть

Оба — вторичные.
