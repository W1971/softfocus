# SoftFocus v2 — Design-Only Analytical Model

**Status:** DESIGN-ONLY  
**Phase:** Phase A — Analytical Exploration  
**Executability:** NONE  
**Last updated:** 2026-02-11

---

## Purpose

This directory contains the **SoftFocus v2 analytical model**.

SoftFocus v2 introduces a new analytical axis
focused on **cognitive structure under sustained responsibility**.

This model is:

- non-clinical
- non-executable
- non-scored
- non-UI
- non-runtime

It exists **exclusively at the design and analytical level**.

---

## v2 Analytical Axis

SoftFocus v2 operates on a distinct canonical axis:

**load predictability → control illusion → cognitive fragmentation**

This axis examines how instability, responsibility,
and compensatory control reshape cognitive structure over time.

v2 does **not** measure recovery, energy, sleep,
or burnout severity as defined in v1.x.

---

## Separation From v1 (Mandatory)

SoftFocus v2 is **strictly separated** from SoftFocus v1.

### v1 (Recovery Model)
- operational
- executable
- scored
- governed under Phase D (Maintenance Mode)
- production and monetizable

### v2 (Cognitive Structure Model)
- design-only
- non-executable
- non-scored
- no UI surfaces
- no runtime presence

**No logic, scoring, types, or contracts may be shared
between v1 and v2.**

---

## Directory Scope

The `frontend/v2/` directory may contain **only analytical artifacts**:

Allowed:
- conceptual descriptions
- axis definitions
- dimensions and signals
- question sets (textual)
- mapping tables
- role-based weighting models
- phase declarations (design-level)

Forbidden:
- TypeScript / JavaScript files
- React components
- scoring logic
- adapters or controllers
- imports into runtime code
- SEO or distribution content

If an artifact can be executed, imported, or rendered,
it does **not** belong in v2.

---

## Governance & Phase Rules

SoftFocus v2 currently operates under:

**Phase A — Analytical Exploration**

This means:

- no implementation
- no scoring
- no UX
- no calculators
- no experiments
- no monetization

Any transition beyond design-level work
requires an explicit phase declaration
and a new bundle contract.

---

## Canonical Constraint

v2 artifacts must not:

- redefine v1 terminology
- reinterpret recovery or burnout
- introduce behavioral guidance
- imply recommendations or actions

SoftFocus v2 provides **orientation and structure only**.

---

## Intentional Incompleteness

SoftFocus v2 is intentionally incomplete.

Its purpose is to:
- stabilize analytical meaning
- prevent premature execution
- allow slow, deliberate model evolution

Completion is defined by **clarity**, not by usability.
