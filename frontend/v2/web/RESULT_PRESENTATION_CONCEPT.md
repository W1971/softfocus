# SoftFocus v2 — Result Presentation Concept (Recognition Moment)

**Status:** DESIGN-ONLY  
**Phase:** Phase C — Analytical Consolidation  
**Surface:** Web  
**Last updated:** 2026-02-11

---

## Purpose

Define how the v2 result is presented so it produces:

> Recognition without prescription.

The result is not a report.
It is a single coherent mirror.

---

## Output Shape (One Screen)

The result is one screen with four blocks:

1) **Name the pattern** (one line)  
2) **Describe the structure** (3 sentences max)  
3) **Explain the dynamic** (one short paragraph)  
4) **Close cleanly** (non-clinical line + exit)

No charts. No dashboards. No breakdown by dimension.

---

## Pattern Naming

Use human names, not model names.

Allowed examples:
- “Compensated instability”
- “Vigilance trap”
- “Silent fragmentation”
- “Reactive drift”

Avoid:
- “High B, medium C”
- “Signal density elevated”

---

## The Three-Sentence Core (Canonical)

Sentence 1: what is happening  
Sentence 2: what sustains it  
Sentence 3: what it tends to produce

Example structure (template only):

- “Your workload is experienced as unstable.”
- “To compensate, you stay mentally ‘on’.”
- “Over time, focus becomes fragmented.”

---

## Non-Clinical Boundary (Minimal)

A single line:
- “Non-clinical.”

No expansions.

---

## Exit Mechanics

Allowed:
- “Save summary”
- “Revisit later”

Forbidden:
- “Next steps”
- “Protocol”
- “Start recovery”

---

## Success Criterion

The result should feel like:
- quiet accuracy
- relief through clarity
- an ending, not a beginning
