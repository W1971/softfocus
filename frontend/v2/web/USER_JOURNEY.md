# SoftFocus v2 — User Journey (Single Linear Path)

**Status:** DESIGN-ONLY  
**Phase:** Phase C — Analytical Consolidation  
**Surface:** Web  
**Last updated:** 2026-02-11

---

## Goal

Deliver one outcome:

> Recognition + orientation without action pressure.

The user completes the experience with:
- a clearer mental model of what is happening
- a stable, non-clinical framing
- no “next steps” requirement

---

## The One Path (No Branching)

**0. Entry (Landing) → 1. Intake → 2. Flow → 3. Recognition → 4. Exit**

There are no alternate routes, dashboards, or follow-up loops.

---

## Step 0 — Entry (Landing)

**User state:** “Something is off; I need clarity.”

**Surface intent:**
- extreme simplicity
- benefits over specs
- one invitation

**Only CTA:** “Start”

No menus. No feature list. No promises.

---

## Step 1 — Intake (30 seconds)

**Purpose:** set the frame and boundaries.

Contains:
- time window (last 3–4 weeks)
- scale meaning (0–3: absent → episodic → regular → structural)
- non-clinical boundary

Ends with: “Continue”

No explanations of dimensions, signals, or scoring.

---

## Step 2 — Assessment Flow (54 questions)

**Format:**
- one question per screen (preferred)
- consistent scale UI
- no progress gamification (no streaks, no “great job”)

**Principle:**
- reduce cognitive load of taking the assessment
- never compete with the content

Optional: minimal progress indicator (quiet, non-salient).

---

## Step 3 — Recognition Moment (Result)

**Output:**
- a single coherent reflection (not a dashboard)
- one primary pattern (from cross-dimension patterns)
- one paragraph of meaning

No prescriptions. No checklists. No protocol.

---

## Step 4 — Exit (Deliberate Ending)

**Exit rule:**
- the experience ends cleanly
- user can leave without feeling incomplete

Optional (allowed):
- “Save summary” (local, non-CRM)
- “Revisit later” (no retention mechanics)

Forbidden:
- “Next steps”
- “Start recovery protocol”
- “Recommended actions”

---

## Success Criterion

If the user thinks:

> “At least now I understand what’s happening.”

We succeeded.

If they ask:

> “What should I do now?”

We failed the v2 contract.
